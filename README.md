# Prova Paraná — Guia do Estudante

Projeto escolar do 2º trimestre.

## Arquivos
- `index.html` — estrutura do site.
- `style.css` — layout, cores e responsividade.
- `script.js` — menu hambúrguer e interações.
- `cartaz_prova_parana.png` — cartaz para divulgação.
- `README.md` — instruções.

## Como executar
Abra o arquivo `index.html` em qualquer navegador.

## Como publicar no GitHub Pages
1. Crie um repositório público no GitHub.
2. Envie `index.html`, `style.css` e `script.js`.
3. No repositório, abra Settings → Pages.
4. Em Source, escolha Deploy from a branch.
5. Selecione a branch `main` e a pasta `/root`.
6. Salve e aguarde a publicação.
7. O GitHub mostrará o link executável do site.

Fonte oficial consultada:
Secretaria de Estado da Educação do Paraná — Prova Paraná:
https://www.educacao.pr.gov.br/programa/prova-parana


## Navegação em páginas
O menu foi configurado para abrir páginas internas do próprio site:

- Sobre → `sobre.html` e `objetivos.html`
- Disciplinas → `disciplinas.html`
